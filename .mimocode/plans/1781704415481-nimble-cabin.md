# Improve Whisper Transcription Quality

## Problem

1. **Final pass identical to live pass**: `transcribeChunk()` uses the same whisper CLI flags for both passes (`src/transcriber.ts:134-149`). The medium model is constrained by the same aggressive thresholds (`--entropy-thold 2.4`, `--logprob-thold -1.0`), so it can't produce meaningfully different output on 15-second chunks.

2. **Hallucinations**: `cleanText()` (`src/transcriber.ts:16-28`) has 11 patterns but misses common whisper artifacts like repeated words, ellipsis sequences, and prompt leakage variants.

## Changes

### 1. Separate whisper flags for final pass

**`src/types.ts`** — add 5 new Config fields:
- `finalEntropyThreshold: 1.5` (was 2.4 for live — more lenient)
- `finalLogprobThreshold: -1.5` (was -1.0 — accept lower-confidence segments)
- `finalNoSpeechThreshold: 0.7` (was 0.6 — more aggressive noise rejection)
- `finalBeamSize: 5` (new — beam search for better accuracy)
- `finalBestOf: 3` (new — more candidates)

**`src/storage.ts`** — add 5 fields to `loadConfig()` merge chain (lines 43-75)

**`src/transcriber.ts`** — branch args at line 134 on `options?.pass`:
- `pass === "final"`: use `finalEntropyThreshold`, `finalLogprobThreshold`, `finalNoSpeechThreshold`, add `--beam-size`, `--best-of`, remove `--no-timestamps`
- `pass === "live"` (default): existing flags unchanged

### 2. Improve hallucination filtering

**`src/transcriber.ts`** — expand `HALLUCINATION_PATTERNS` (line 16):
- Prompt leakage variants: `консультация.*вопросы`, `обсуждение.*ответы`
- YouTube/video artifacts: `лайк`, `комментарий`, `подписка`
- Whisper artifacts: `...` (ellipsis), `— — —` (em-dash sequences)
- Repeated word detector: collapse 3+ identical consecutive words to 1
- Min-length guard: if cleaned text < 3 chars, return empty

### 3. Tests

**`src/transcriber.test.ts`** — add tests for:
- New hallucination patterns
- Repeat collapsing
- Short fragment rejection
