# Plan: `meet dashboard` — HTML Meeting Stats Dashboard

## Overview

Add a `meet dashboard` CLI command that scans `~/Meetings/`, parses `meta.md` files and transcripts, and generates a single self-contained HTML file with interactive charts and stats.

## Data Sources

- **`~/Meetings/`** — 82 directories (some early entries are `.md` files, skip those)
- **`meta.md`** per meeting dir: title, date (`DD.MM.YYYY HH:MM`), mode, tags
- **`transcript.md`** per meeting dir: timestamps for duration, text for word count

## Stats to Generate

| Stat | Source | Method |
|------|--------|--------|
| Total calls | directory count | `readdir` + filter dirs |
| Duration per call | transcript timestamps | Parse first/last `**[HH:MM:SS]**` |
| Words per call | transcript text | Split on whitespace, count |
| Calls per week | meta.md dates | Group by ISO week |
| Calls per month | meta.md dates | Group by YYYY-MM |
| Tag distribution | meta.md tags | Count per tag |
| Day-of-week heatmap | meta.md dates | Mon-Sun buckets |
| Hour-of-day distribution | meta.md dates | 0-23 buckets |

## Implementation

### New file: `src/dashboard.ts`

1. **`collectMeetings()`** — scan `~/Meetings/`, for each dir:
   - Parse `meta.md` → title, date, mode, tags
   - Parse `transcript.md` → first/last timestamp → duration; word count
   - Return array of `MeetingStats` objects

2. **`computeStats(meetings)`** — aggregate:
   - Total count
   - Calls per week/month (Map<string, number>)
   - Tag distribution (Map<string, number>)
   - Day-of-week histogram (7 buckets)
   - Hour-of-day histogram (24 buckets)
   - Avg/min/max duration and word count

3. **`generateDashboard(stats, outputPath)`** — produce single HTML file:
   - Inline CSS (dark theme, clean layout)
   - Inline Chart.js from CDN (`<script src="https://cdn.jsdelivr.net/npm/chart.js">`)
   - Data embedded as `<script>const DATA = {...}</script>`
   - Charts: bar (calls/week), bar (calls/month), pie (tags), heatmap (day-of-week), histogram (hour-of-day)
   - Summary cards: total calls, avg duration, avg words, date range

### Modify: `src/cli.ts`

Add command:
```ts
program
  .command("dashboard")
  .description("Generate HTML dashboard with meeting stats")
  .option("--output <path>", "Output file path", "~/Meetings/dashboard.html")
  .action(async (opts) => { ... });
```

### Output

Single HTML file at `~/Meetings/dashboard.html` (configurable via `--output`).
Opens in any browser. No server needed. Charts powered by Chart.js CDN.
