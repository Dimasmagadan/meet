# Возможности

<p class="lead">Исчерпывающий каталог того, что <strong>meet</strong> умеет сегодня. Источник истины — CLI в <code>src/cli.ts</code>; эта страница его отражает.</p>

<!-- FEATURES:core-recording -->
## Основная запись

- **Приложение в строке меню** — `native/MenuBar/` собирает Dock-less `Meet.app`, который управляет `meet` в headless-режиме из строки меню: клик по иконке, ввод названия, старт/стоп/пауза/продление — без терминала. Опциональный автозапуск при входе; использует весь конвейер через shell-out + POSIX-сигналы.
- **Панель расшифровки в чёлке** (MacBook Pro 14"/16", M1 Pro и новее) — во время записи наведите курсор на физическую чёлку экрана, чтобы увидеть прокручиваемый хвост живой расшифровки; убираете курсор — панель скрывается.
- **Автозапуск по календарю** — включите «Auto-Record Calendar Calls» в строке меню, чтобы запись стартовала автоматически в момент начала события в календаре со ссылкой Zoom/Meet/Teams/Webex/Whereby/Telemost/Jazz/Kontur. Без диалога подтверждения; отклонённые события, события на весь день и блоки Free/OOO пропускаются. Авто-стоп в назначенное время окончания (+ запас, урезаемый для встреч подряд без перерыва). В меню в режиме ожидания показывается ближайшее подходящее событие, чтобы функция оставалась наблюдаемой.
- **Запись встречи в foreground** — `meet start "Title"` пишет микрофон + звук системы, расшифровывает куски вживую и блокирует терминал до остановки.
- **Режим только микрофон** — `meet start --mic "Title"` для встреч вживую, интервью или телефона на громкой связи.
- **Двухканальный захват** — Swift-`AudioCapture` параллельно пишет микрофон (AVAudioEngine + VoiceProcessing IO) и звук системы (ScreenCaptureKit) в атомарные 15-секундные WAV-куски; `excludesCurrentProcessAudio` защищает от обратной связи.
- **Атомарная передача кусков** — пишет `*.wav.tmp`, финализирует заголовок, затем переименовывает в `*.wav`. Конвейер никогда не расшифровывает недописанный файл.
- **Эхоподавление VoiceProcessing** — `--voice-processing` (опционально) для более чистого звука, когда вы без наушников.
- **Авто-стоп** — настраиваемая максимальная длительность (`--max-duration`, по умолчанию 60 мин) и тайм-аут по тишине/отсутствию речи (`--no-text-timeout`, по умолчанию 10 мин).
- **Тайм-аут тишины на стороне захвата** — `--silence <sec>` останавливает запись после N секунд тишины.
- **Горячие клавиши во время записи** — `q` стоп и финализация в фоне · `s` стоп в foreground · `n` закончить и начать следующую встречу · `p` пауза/возобновление · `e` продлить лимит +15 мин · `a` спросить opencode. (Кириллические алиасы: `й ы т ф у`.)

## Качество расшифровки

- **Локальный whisper.cpp (Metal)** — каждый кусок расшифровывается на устройстве через `whisper-cli`; GPU включён по умолчанию, без сети.
- **Двухмодельная стратегия** — small-модель (`ggml-small.bin`, 466 МБ) вживую для низкой задержки; medium-модель (`ggml-medium.bin`, ~1,5 ГБ) на финальном проходе.
- **Оптимизация под русский, настраиваемо** — по умолчанию `-l ru`; любой поддерживаемый whisper язык через `config.language`.
- **Фильтр шума и галлюцинаций** — `cleanText()` отбрасывает `[music]`, `♪`, титры субтитров и артефакты в духе «thank you for watching».
- **Тюнингованные флаги whisper** — `--suppress-nst --entropy-thold 2.4 --logprob-thold -1.0 --no-speech-thold 0.6`.
- **Свой словарь** — горячо-перезагружаемый `vocabulary.json` подмешивает редкие имена/жаргон в `--prompt` whisper (мягкое смещение, не жёсткая переопределка).
- **Фразеонимус** — горячо-перезагружаемый `phrasebook.json` применяет regex/текстовые замены (с обратными ссылками `$1`–`$9`) ко всему выводу транскрипта.

## Идентификация спикеров

- **Метки по источнику** — вживую микрофон это `Me`, а звук системы это `Others`; диаризация не нужна.
- **Диаризация спикеров** — на финальном проходе звук системы склеивается и прогоняется через диаризатор FluidAudio, переписывая записи в `Speaker 1`, `Speaker 2`… по первому появлению. Пишет `speakers.json`.
- **Переименование спикеров** — `meet rename <dir> "Speaker 1" "Женя"` правит метку в `transcript*.md`, `index.md` и `speakers.json` (идемпотентно).
- **Кросс-сессионный реестр спикеров** (опционально, биометрия) — хранит голосовые эмбеддинги; косинусно сопоставляет известные голоса между встречами, чтобы одного и того же человека размечать автоматически.
- **Живые метки спикеров** (нужен реестр) — во время записи каждый расшифрованный чанк получает дешёвый локальный голосовой отпечаток (`AudioAnalysis embed`, ~0.3 с на ANE), который сверяется с реестром: названные люди сразу видны по имени в живом транскрипте и панели в «чёлке», безымянные знакомые голоса — как `Speaker N`. Реестр только читается; финальный проход остаётся источником истины.
- **Статистика времени речи** — длительность и процент по каждому спикеру, рендерятся как футер `## Talk Time` в каждом финализированном транскрипте.
- **Подсказки имён спикеров** — `meet speakers suggest <dir>` печатает время речи, уверенность совпадения по реестру и (для встреч с автозапуском по календарю) список участников напротив ещё не названных спикеров, с готовыми строками `meet rename` для копирования. Сам ничего не переименовывает.

## A/B-сравнения

- **Проход Parakeet-TDT** (`parakeetComparePass`, по умолчанию вкл.) — повторно расшифровывает те же куски через Parakeet-TDT и пишет `transcript.parakeet.md` + `ab-report.json` для ручного сравнения.
- **A/B диаризатора** (`diarizationAbPass`, опционально) — повторная диаризация через офлайн-конвейер VBx, пишет `diarization-ab-report.json` (процент совпадения, свопы, дельты времени речи, косинус эмбеддингов). Никогда не трогает `transcript.md`.
<!-- /FEATURES:ab-comparison -->

<!-- FEATURES:live-attention -->
## Внимание и выжимка вживую

- **Оповещения по словам-триггерам** — следит за живой расшифровкой звука системы (никогда за вашим микрофоном) за словами из `triggers.json` (обычно ваше имя) и шлёт macOS-уведомление + терминальный рекап. С рейт-лимитом.
- **Живая экстрактивная выжимка** — накатный `summary.md` рядом с `transcript.md`: ключевые точки TextRank, кандидаты в action items и участники. Запускается примерно каждые 2 мин и ставится на паузу при нехватке CPU/памяти.
- **Q&A через opencode во время звонка** — нажмите `a`, чтобы задать вопрос по живому транскрипту.
<!-- /FEATURES:live-attention -->

<!-- FEATURES:finalization -->
## Конвейер финализации

- **Финальный перепроход расшифровки** — все куски повторно расшифровываются medium-моделью с фильтром эха/дубликатов.
- **Гейтинг тишины** — куски ниже RMS-порога пропускаются.
- **Перезапись отсортированного markdown** — записи чередуются по тайм-коду, `Me` / `Speaker N`, с футером Talk Time.
- **Финализация в фоне или foreground** — `meet finalize <dir> --background` освобождает терминал; прогресс через `meet status`.
- **Индекс opencode** (`opencodeIndexPass`, опционально) — генерирует `index.md` (Summary / Decisions / Action Items). Фейлится безопасно.
<!-- /FEATURES:finalization -->

<!-- FEATURES:post-processing -->
## Постобработка

- **Контекст git-репозитория** — `meet start --repo <path>` (по умолчанию: cwd) добавляет строку `- Repo: name @ sha (branch)` в `meta.md`. `meet link <dir> <repoPath>` перевешивает её позже. Чисто локально, без сети.
- **Интерактивный выбор тегов** — тегирование встреч из `tags.md` при остановке записи (пропускается в `--headless`).
- **Метаданные встречи** — каждая встреча пишет `meta.md` (заголовок, дата, режим, теги, репо).
- **HTML-дашборд** — `meet dashboard` генерирует фильтруемый `~/Meetings/dashboard.html` (статистика, теги, колонка репо).
<!-- /FEATURES:post-processing -->

<!-- FEATURES:import-batch -->
## Импорт и пакетная обработка

- **Импорт файлов** — `meet transcribe <files...>` конвертирует m4a/mp4/wav/и т.д. через ffmpeg и расшифровывает файл целиком для лучшего контекста.
- **Пакетно** — `meet transcribe *.m4a` расшифровывает много файлов; заголовки из имён файлов; авто-тег `batch-transcription`.
- **Индекс на стороне импорта** — `index.md` (Summary / Decisions / Action Items) для импортов; пропустите через `--no-index`.
<!-- /FEATURES:import-batch -->

<!-- FEATURES:reliability -->
## Надёжность и производительность

- **Файловые блокировки** — активной записи, финализатор сессии (`O_EXCL`) и глобальная блокировка финального прохода, сериализующая тяжёлые medium-проходы во всей системе. Все авто-чистят зависшие записи через `isPidAlive`.
- **Атомарные записи** — каждая персистентная запись это `.tmp` → `rename()`.
- **Append-only лог транскрипта** — `entries.jsonl` это надёжный источник истины; живой расшифрованный текст никогда не теряется, даже если финальная модель отсутствует.
- **Детектор зависших сессий** — `meet start` предупреждает о потерянных сессиях и печатает команду восстановления `meet finalize`.
- **Гейты системной нагрузки** — тяжёлые проходы отступают при перегрузке; **живой путь остаётся без гейтов**, чтобы запись никогда не застопорилась.
- **Приоритет процесса** — whisper-cli + AudioAnalysis запускаются под `taskpolicy -c utility`, чтобы захват звука сохранял приоритет.
- **Видимость отставания живой очереди** — строка статуса желтеет, когда расшифровка копится (~2 мин). Только видимость — куски не отбрасываются.
<!-- /FEATURES:reliability -->

## Справочник CLI

<div class="table-wrap" markdown="1">

| Команда | Описание |
|---|---|
| `meet start "Title"` | Запись микрофона + звука системы (foreground) |
| `meet start --mic "Title"` | Запись только микрофона |
| `meet transcribe <files...>` | Расшифровка аудио/видео файлов |
| `meet setup` | Проверка зависимостей и конфигурации |
| `meet doctor [mic\|full]` | 12-секундная проверка здоровья захвата + диагностика |
| `meet list` | Список прошлых встреч |
| `meet finalize <sessionDir>` | Финализация остановленной записи (`--background`) |
| `meet tag <sessionDir> <tags...>` | Поставить теги для идущей записи |
| `meet status` | Показать активные записи/финализации |
| `meet rename <dir> <id> <name>` | Переименовать метку диаризованного спикера |
| `meet link <dir> <repoPath>` | Прикрепить/заменить контекст git-репозитория |
| `meet speakers list / forget` | Управление кросс-сессионным реестром спикеров |
| `meet speakers suggest <dir>` | Подсказать имена спикеров по участникам из календаря + совпадениям реестра |
| `meet dashboard` | Сгенерировать HTML-дашборд |
| `meet bin-path` | Напечатать разрешённые пути раннера (для приложения в строке меню) |

</div>

### Опции `start`

<div class="table-wrap" markdown="1">

| Опция | Описание | По умолчанию |
|---|---|---|
| `--mic` | Режим только микрофон | выкл |
| `--silence <sec>` | Тайм-аут тишины захвата (0 = выкл) | 0 |
| `--max-duration <min>` | Авто-стоп через N минут | 60 |
| `--no-text-timeout <min>` | Авто-стоп после N обработанных минут без текста | 10 |
| `--voice-processing` | Включить эхоподавление VoiceProcessing IO | выкл |
| `--no-summary` | Отключить живую экстрактивную выжимку | выкл |
| `--repo <path>` | Прикрепить контекст git-репозитория из `<path>` | cwd |
| `--attendees <names>` | Имена участников через запятую (из автозапуска по календарю) | нет |

</div>
