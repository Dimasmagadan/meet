Локально · macOS · Apple Silicon

Встречи, расшифрованные
прямо на вашем Mac.

meet записывает ваш микрофон и звук системы, расшифровывает всё на устройстве через whisper.cpp и сохраняет аккуратный markdown с тайм-кодами. Без облака, без API-ключей, без подписки — данные никогда не покидают ваш компьютер.

Почему meet

Ключевые отличия — то, что делает этот инструмент лучшим выбором для приватных, офлайн-конспектов встреч.

  • 100% локально и приватно. Аудио расшифровывается на вашей машине через whisper.cpp. Ничего не загружается — ни одного раза: без аккаунта, без API-ключей, без третьих сторон.
  • Работает офлайн. После скачивания модели весь конвейер работает без сети. Поездки, перелёты, плохой Wi-Fi в кофейне — не помеха.
  • Без подписки и без поминутной оплаты. Бесплатно навсегда, MIT-лицензия, открытый код. Записывайте сколько угодно.
  • Ускорение на GPU Metal. whisper.cpp использует GPU Apple Silicon по умолчанию — быстрая расшифровка в реальном времени без отдельной видеокарты.
  • Двухканальная запись. Вас (микрофон) и собеседников (звук системы) пишет раздельно, поэтому спикеры размечаются по источнику с самого первого куска.
  • Настоящая диаризация. На финальном проходе звук системы разбивается на Speaker 1, Speaker 2… со статистикой времени разговора по каждому спикеру.
  • Вживую, а не постфактум. Куски расшифровываются прямо во время разговора; накатная выжимка и оповещения внимания появляются в ходе звонка.
  • Вывод в простом тексте, который ваш. Каждая встреча — папка markdown-файлов в ~/Meetings/: версонируйте, грепайте, автоматизируйте.

На всю встречу целиком

От первой секунды записи до поискимого, размеченного, подписанного спикерами протокола. Несколько ярких моментов — все возможности см. на отдельной странице.

запись

Двухканальная запись

Микрофон (вы) + звук системы (остальные) пишутся параллельно, атомарно передаются 15-секундными WAV-кусками.

качество

Двухмодельный конвейер

Быстрая small-модель вживую, более качественная medium-модель на финальном проходе — с фильтром эха и дубликатов.

спикеры

Диаризация + время речи

Звук системы разбивается на подписанных спикеров с футером по длительности и проценту для каждого.

вживую

Оповещения внимания

Получайте macOS-уведомление, когда во время звонка звучит ваше имя или слово-триггер.

вживую

Накатная выжимка

Выжимка TextRank с учётом нагрузки пишется рядом с транскриптом прямо во время записи.

настройка

Словарь и фразеонимус

Горячо-перезагружаемый словарь смещает декодер; фразеонимус-regex переписывает транскрипт на лету.

импорт

Расшифровка готовых файлов

Дайте ему m4a/mp4/wav — пакетно или по одному — для встреч, записанных в других местах.

надёжность

Защита от сбоев по дизайну

Атомарные записи, append-only лог транскрипта и детектор зависших сессий — ничего не теряется при жёстком завершении.
